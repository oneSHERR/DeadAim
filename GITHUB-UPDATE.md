# Как обновить GitHub

1. Распакуй архив и открой папку `deadaim`.
2. Открой свой репозиторий на GitHub → Add file → Upload files.
3. Перетащи **всё содержимое** папки `deadaim`: файлы и папку `tests`. Саму внешнюю папку `deadaim` не загружай.
4. Нажми Commit changes. Файлы с одинаковыми именами обновятся, новые добавятся.
5. Дождись завершения публикации GitHub Pages и обнови сайт сочетанием Ctrl+F5.

## Что заменить

Все совпадающие файлы из архива — новыми версиями. Включая `index.html`, `app.js`, `style.css`, `engine.js`, `cloud.js`, `firebase-config.js`, `dashboard.js`, `training.js`, документацию, `package.json`, `server.js` и тесты. Новый `identity.js` обязателен для входа по нику. Конфигурация Firebase проекта `deadaim` уже заполнена.

## Что оставить

Не удаляй репозиторий. Сохрани настройки GitHub Pages, папку `.github`, файл `CNAME` (если они есть) и свои файлы, которых нет в архиве. `.nojekyll` и `.gitignore` из архива тоже можно загрузить. `index.html` должен остаться в корне рядом с `app.js`.

## Firebase настраивается отдельно

Загрузка файлов на GitHub не создаёт базу и не публикует правила Firebase. Для статистики друзей нужны включённый Anonymous в Authentication, база Cloud Firestore и опубликованные правила из `firestore.rules`. Пошаговая инструкция — `FIREBASE.md`.

В этой версии нет кнопки Google: введи ник → «Подключиться по нику» → создай группу или вступи по коду. Настоящий вход и обмен результатами ещё нужно проверить после настройки Firebase.
