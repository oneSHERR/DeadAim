# Подключаем общую статистику друзей

Сайт по-прежнему размещается на GitHub Pages. Firebase отвечает за анонимный вход по нику и общую базу результатов. Обычные тренировки не зависят от Firebase.

Конфигурация проекта `deadaim` уже добавлена в этот архив. Повторно вставлять её не нужно.

## 1. Где находится конфигурация

В [Firebase Console](https://console.firebase.google.com/) открой проект → шестерёнка → Project settings → General → Your apps.

Выбери приложение со значком `</>`. Если его нет, добавь веб-приложение. В SDK setup and configuration выбери Config. Скопируй объект `firebaseConfig`.

При подключении другого проекта меняется объект в `firebase-config.js`:

```js
export const firebaseConfig = {
  apiKey: "значение из Firebase",
  authDomain: "значение из Firebase",
  projectId: "значение из Firebase",
  storageBucket: "значение из Firebase",
  messagingSenderId: "значение из Firebase",
  appId: "значение из Firebase"
};
```

Эта веб-конфигурация предназначена для клиента. Приватные ключи, service-account JSON и пароли сюда не вставляются.

## 2. Включить вход

Security → Authentication → Sign-in method → Anonymous → Enable → Save. Google включать не нужно.

Authentication → Settings → Authorized domains: добавь домен GitHub Pages, например `имя.github.io` (без `https://` и пути репозитория). Для локальной проверки добавь `localhost` и открывай `http://localhost:4173`. Домен `127.0.0.1` для входа не используй. В приложении введи ник и нажми «Подключиться по нику»: SDK загрузится, и анонимный вход произойдёт без окна регистрации.

## 3. Создать или проверить Firestore

Build → Firestore Database. Если база отсутствует, создай базу `(default)` в production mode, выбрав подходящий регион. Если база уже есть, используй её: удалять ничего не нужно.

**Если в проекте уже есть другие приложения или правила, не заменяй их вслепую.** Пришли текущий текст вкладки Rules — добавим блок `deadaimRooms` в существующие правила. Разрешающие правила вида `match /{document=**} { allow read, write: if true; }` перекрывают ограничения этого тренажёра, поэтому правила всего проекта нужно проверить вместе.

Для отдельного пустого проекта: открой Rules, вставь содержимое `firestore.rules`, затем Publish. Правила не включаются от одной загрузки файла на GitHub — их нужно опубликовать в Firebase.

В этой версии используются только коллекция `deadaimRooms` и её подколлекции `results`. Список групп закрыт, код приглашения открывает возможность вступить. Прочитать результаты могут участники; записать результат — только под своим UID. Чужие результаты нельзя изменять. До 20 участников в группе.

## 4. Обновить сайт

Загрузи содержимое папки `deadaim` в свой репозиторий, заменив старые файлы. `index.html` должен остаться в корне. Дождись обновления GitHub Pages и обнови вкладку с Ctrl+F5.

## 5. Проверить с другом

1. Введи ник, нажми «Подключиться по нику», затем «Создать группу».
2. Скопируй код из интерфейса и передай другу. Сохрани код: после перезагрузки его нужно ввести снова.
3. Друг вводит свой ник в своём браузере, подключается и нажимает «Вступить», указав код.
4. Каждый завершает тренировку с одинаковыми режимом, сложностью и длительностью.
5. В таблице выбери эти параметры и нажми «Обновить».
6. Проверь, что результат виден обоим. В другом браузере без членства результаты группы должны быть недоступны.

Обновление таблицы выполняется по кнопке; выбираются последние 200 результатов группы, затем лучшие результаты участников для выбранных параметров. Это не глобальный рейтинг за всё время. Для постоянных рекордов и больших групп можно следующим этапом добавить серверную агрегацию.

## Профиль без регистрации

Firebase хранит анонимный ID в этом браузере. Перезагрузка и смена ника не меняют ID. Другой браузер, приватное окно или очистка данных создают нового игрока. Ник не является паролем и не восстанавливает прежний ID. Одинаковые ники разрешены, результаты различаются по ID.

## Как хранятся данные

- Личная история (500 последних серий) и сенса — в браузере. Синхронизации личной истории между устройствами пока нет.
- В группу отправляются только новые завершённые серии, пока выполнен вход и выбрана группа. Локальные старые результаты не отправляются автоматически.
- В Firestore сохраняются UID, выбранный ник, режим, сложность, длительность, попадания, выстрелы, точность, интервал и серверное время. Email и настройки мыши в таблицу не записываются.
- При сетевой ошибке результат остаётся локально. Можно повторить отправку кнопкой до перезагрузки страницы. При закрытии страницы очередь повторов теряется; сам результат остаётся в локальной истории.
- После выхода из группы её ранее полученные результаты остаются у остальных участников. Результаты можно удалить администратором через Firebase Console; это не удаляет локальную историю.
- Клиент считает результаты сам. Правила ограничивают доступ и проверяют формат, но не подтверждают честность игры. Таблица предназначена для друзей, а не турниров с призами.

## Статус проверки

Локальные режимы и расчёты проверены автоматическими тестами. Реальный анонимный вход, запись/чтение двумя аккаунтами и компиляция правил требуют подключённого Firebase-проекта. До выполнения проверки выше облачный модуль следует считать подготовленным к подключению, а не проверенным в эксплуатации.

Основа подключения: [Firebase Web setup](https://firebase.google.com/docs/web/setup), [Anonymous sign-in](https://firebase.google.com/docs/auth/web/anonymous-auth), [проверка полей правилами Firestore](https://firebase.google.com/docs/firestore/security/rules-fields).
