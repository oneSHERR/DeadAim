# DEADAIM

Браузерный aim-тренажёр для практики наведения с чувствительностью CS2. Vanilla JavaScript, Canvas 2D с перспективной проекцией трёхмерной сцены. Локальная тренировка работает без внешних зависимостей и сборки. Опциональная статистика друзей использует Firebase Auth и Cloud Firestore; SDK загружается с Google CDN только после нажатия кнопки входа.

## Запуск

Установи Node.js 20 или новее и выполни в папке проекта:

```sh
npm start
```

Открой http://127.0.0.1:4173 в настольном браузере с мышью. Двойной клик по HTML не подходит: ES-модулям нужен HTTP-сервер. `npm test` запускает тесты сенсы, попаданий, разминки, калибровки, анализа и жизненного цикла серии.

## GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузи **содержимое** папки `deadaim` в корень репозитория (включая `.nojekyll`).
3. В Settings → Pages выбери Deploy from a branch → main → / (root) → Save.
4. После публикации открой адрес, который покажет GitHub Pages. Относительные пути поддерживают адрес вида `username.github.io/repository/`.

Ничего устанавливать на хостинге не требуется. `server.js`, тесты и `package.json` нужны только для локальной разработки. Секретов в клиенте нет. Для общей статистики подключи Firebase по FIREBASE.md.

## Режимы

- **Флики:** три цели, попавшая цель заменяется новой. ЛКМ — одиночный выстрел.
- **Точность:** меньшие цели для микрокоррекций.
- **Трекинг:** удерживай ЛКМ и сопровождай движущуюся цель. Результат — доля времени всей серии, проведённая на цели с нажатой ЛКМ.
- ESC — пауза; R — сброс текущей серии. При переключении вкладки тренировка ставится на паузу. Настройки блокируются до завершения серии либо её сброса из паузы.

История последних 500 серий (8 отображаются в списке) и настройки сохраняются только в localStorage текущего браузера. При недоступном хранилище приложение продолжает работать без сохранения. Отображаемая история — реальные результаты, без демонстрационных записей.

## Сенса и ограничения

Введи `sensitivity` из консоли CS2. По умолчанию используется коэффициент 0.022 градуса на единицу перемещения мыши и единицу сенсы по обеим осям:

```text
angle = mouse movement × sensitivity × 0.022 × calibration
eDPI = DPI × sensitivity
cm/360 = 360 × 2.54 / (DPI × sensitivity × 0.022)
```

DPI в интерфейсе служит для расчётов и не меняет аппаратный DPI мыши. Значение см/360 — теоретическое для базовой сенсы CS2, до калибровки. Если используется нестандартный m_yaw, учти его в множителе; отдельные нестандартные m_pitch и zoom sensitivity не моделируются.

Вертикальный FOV ≈73.74° (90° по горизонтали при 4:3); нативная проекция расширяет горизонтальный обзор по соотношению сторон арены. 4:3 stretched растягивает 4:3 на всю арену. Для сравнения с игрой используй полный экран. Поворот камеры не зависит от размера окна или FPS.

Приложение запрашивает `unadjustedMovement: true`. Поддержка raw input зависит от браузера и ОС; старые реализации могут игнорировать опцию. При явном отказе NotSupportedError следующий клик использует обычный ввод. Нельзя гарантировать абсолютное совпадение ощущений с CS2 на всех системах. Проверь физический путь полного оборота: если браузер требует 60 см, а CS2 50 см, поставь калибровку 1.2. Сохраняй одинаковый DPI и масштаб браузера 100%.

Документация ввода: https://developer.mozilla.org/en-US/docs/Web/API/Element/requestPointerLock

Это самостоятельный тренажёр наведения, не симуляция Source 2. Нет моделей оружия, отдачи, передвижения, зума и сетевой игры. Для игры нужна мышь; сенсорное управление не реализовано. Не связан с Valve.


## Что нового в 2.0

- Помощник калибровки: измерение оборота камерой, поля физического пути и поправка с учётом текущего множителя. ESC ставит измерение на паузу, R сбрасывает; после ESC и R можно выйти из теста.
- Разминка на 5 или 10 минут: пять режимов по 60/120 секунд с автоматическим переходом. Завершённые этапы сохраняются отдельно. R повторяет текущий этап, поэтому общая длительность увеличивается. Остановка доступна после ESC.
- Рекорды и графики последних 20 сопоставимых серий из сохранённых 500: точность, попадания/с, средний интервал. Параметры сравнения — режим, сложность и длительность. Для трекинга используется удержание. Интервал включает время до первого попадания, это не измерение чистой реакции.
- Режим «Голова»: цели на одинаковой высоте. «Стрейф»: горизонтальные перемещения с паузами и сменой направления.
- Карта выстрелов после серии (до 1000), оценка недовода, перелёта, вертикальной ошибки. Предполагаемая цель выбирается как ближайшая к прицелу; классификация не знает намерений игрока. Карта последней серии живёт до перезагрузки, числовые результаты сохраняются.
- Группа друзей: анонимный вход по нику, приглашение кодом, общая таблица по параметрам тренировки. Подключение: [FIREBASE.md](FIREBASE.md).

Проверки локального приложения используют контролируемые события мыши и часы. Они не заменяют проверку настоящей мышью в браузере. Firebase и правила требуют отдельной проверки в твоём проекте; без конфигурации подключение выключено.
