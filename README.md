# DEADAIM 3.0

Браузерный aim-тренажёр для мыши и клавиатуры. Тёмный интерфейс с лаймовыми акцентами, чувствительность из CS2, аккаунты Firebase, друзья и личная статистика. Статический сайт: подходит для GitHub Pages, сборка и собственный сервер не нужны.

## С чего начать

1. Обновление GitHub: [GITHUB-UPDATE.md](GITHUB-UPDATE.md).
2. Включение аккаунтов и правил: [FIREBASE.md](FIREBASE.md).
3. Открой опубликованный сайт в настольном Chrome или Edge.
4. Войди по email и паролю или выбери «Тренироваться без аккаунта».
5. Укажи сенсу CS2 и DPI, выбери тренировку и нажми «Начать».

## Тренировки

| Режим | Что делать |
| --- | --- |
| Флики | Быстро переводить прицел между тремя целями |
| Микроточность | Попадать в маленькие цели короткими движениями |
| Трекинг | Удерживать ЛКМ и сопровождать движущуюся цель |
| Уровень головы | Выполнять горизонтальные переводы |
| Стрейф-цель | Попадать по цели, меняющей направление и делающей паузы |
| Удержание угла | Дождаться выхода из-за укрытия; стена блокирует выстрелы |
| Флик + доводка | Доводить прицел после небольшого смещения цели |
| Шесть целей | Поддерживать ритм точных попаданий по шести мишеням |
| Движущиеся головы | Переключаться между четырьмя движущимися целями |
| Проверка углов | Двигаться A / D вдоль проёмов и открывать линию огня |
| Стена · 3 цели | На стене всегда три мишени; поражённая заменяется новой |
| Зачистка · 50 | Уничтожить 50 одновременно появившихся целей до конца таймера |

В зачистке цели не возрождаются. После последнего попадания серия заканчивается сразу; результат — время и точность. При истечении таймера сохраняется количество уничтоженных целей.

Серия: 30 / 60 / 120 секунд; три сложности. Перед стартом — отсчёт 3 секунды, после паузы — 1 секунда. Разминки на 5 и 10 минут содержат пять базовых упражнений; отсчёты добавляются к активному времени.

### Форматы

- **Стандарт** — постоянные параметры.
- **Адаптивный** — размер вновь появляющихся целей уменьшается после серии попаданий и увеличивается после промахов. В трекинге и зачистке 50 размер фиксирован.
- **Челлендж** — одинаковый код, режим, сложность и длительность дают одинаковую последовательность генерации. Для движущихся целей результат также зависит от момента выстрела. Версия алгоритма — v3.

Рекорды разделяются по режиму, сложности, длительности, формату и коду челленджа. Завершённая зачистка всегда выше незавершённой; среди завершённых выигрывает меньшее время.

## Управление и сенса

- Мышь — прицел; ЛКМ — выстрел; в трекинге держи ЛКМ.
- Esc — пауза; R — начать текущую серию заново.
- A / D или стрелки — движение только в проверке углов.
- «Выбрать другую тренировку» — закончить незавершённую серию без результата.
- Вкладка потеряла фокус или кадр задержался больше секунды — игра встаёт на паузу.

Угловая чувствительность: `0.022° × sensitivity × calibration` на единицу движения мыши. `eDPI = DPI × sensitivity`; расчётный `см/360° = 360 × 2.54 / (DPI × sensitivity × 0.022)`. DPI в интерфейсе не меняет DPI самой мыши. Начни с множителя 1. Для совпадения с CS2 используй одинаковые DPI, масштаб браузера 100%, полный экран и помощник калибровки 360°.

Запрашивается raw input через Pointer Lock. Если браузер его не поддерживает, нажми «Начать» ещё раз для обычного ввода и проверь калибровку. Точное совпадение зависит от браузера, ОС и мыши. Это самостоятельный тренажёр: без оружия, отдачи и точного движения CS2; режим углов использует упрощённое боковое перемещение. Смартфон подходит для просмотра профиля, для тренировки нужна мышь.

## Аккаунты, друзья и статистика

- Регистрация: уникальный ник (3–20 латинских букв, цифр или `_`), email и пароль от 8 символов.
- Регистр ника не важен: `Player_7` и `player_7` — один ник.
- Вход — по email и паролю. Email не показывается другим игрокам.
- Подтверждение почты не требуется; для восстановления пароля нужен доступ к указанному адресу. Не используй чужую почту.
- Поиск друга по точному нику, отправка/отмена заявки, принятие/отклонение, удаление из друзей.
- После принятия заявки доступны результаты друга. Сравнение использует текущие настройки тренировки; ниже видны его последние серии.
- Личные рекорды, график, история и карта промахов. Облачный экран читает последние 500 серий, график показывает последние 20 сопоставимых результатов.
- Сенсу, DPI, калибровку, цвет прицела, формат изображения и звук можно сохранить и загрузить через профиль.
- При потере связи результат остаётся локально. Нажми «Повторить отправку» или «Синхронизировать статистику» после восстановления связи.
- У гостей отдельная история. Кнопка «Перенести гостевую историю» переносит её в текущий аккаунт; исходные записи остаются на устройстве.

Регистрация в том же браузере привязывает существующий анонимный аккаунт к email, сохраняя UID. Вход в уже существующий email открывает именно этот аккаунт. Старые групповые записи v2 остаются в Firebase; новый интерфейс использует личную историю и друзей вместо комнат. Переносится гостевая история с текущего устройства, автоматического импорта удалённых комнат нет.

Пароли обрабатывает Firebase Authentication. В Firestore нет email и паролей. Правила разрешают запись результатов владельцу, чтение — владельцу и принятым друзьям; настройки мыши доступны только владельцу. Клиент сам рассчитывает результат: система предназначена для дружеского сравнения, без серверного античита. Правила для прототипа проверены локально; перед широким публичным запуском нужен отдельный обзор правил, квот и защиты от спама.

## Локальный запуск

Нужен Node.js 20+:

```sh
npm start
```

Открой `http://127.0.0.1:4173`. Двойной клик по index.html не подходит для ES-модулей. Установка npm-пакетов для запуска сайта не требуется. Firebase SDK загружается из официального CDN только при подключении аккаунта.

## Проверки

```sh
npm test
```

23 теста: математическая модель, игровые сценарии, отсчёт/пауза/разминка, формирование результатов и выбор способа регистрации.

Отдельные правила Firestore (Java 21+, Node.js и локальный Firebase CLI):

```sh
npm install --no-save firebase @firebase/rules-unit-testing firebase-tools
npx firebase emulators:exec --only firestore --project demo-deadaim "node --test tests/firestore.emulator.mjs"
```

Этот тест предназначен только для эмулятора на `127.0.0.1:8080` и тестового проекта `demo-deadaim`, очищает его тестовую базу. 7 сценариев проверяют уникальность ников, заявки, реальные запросы списка друзей/истории, приватность настроек, запрет чужих записей и некорректных результатов, отзыв доступа.

Проверено: 23 обычных теста + 7 сценариев правил на Firestore Emulator 1.22.0. Интерфейс просмотрен в Chrome при ширине 1440 и 390 px, без ошибок JavaScript и горизонтального переполнения. Автоматизированный браузер не предоставил Pointer Lock, поэтому игра с физической мышью требует проверки на опубликованном сайте. Регистрация и обмен результатами в рабочем проекте deadaim ещё не проверены: сначала включи Email/Password и опубликуй правила.
